## Downloaded by the user's machine at first run (NOT redistributed by this project)

| Component | Licence | Source |
|---|---|---|
| [yt-dlp](https://github.com/yt-dlp/yt-dlp) | Unlicense | `yt-dlp/yt-dlp` GitHub releases |
| [FFmpeg](https://ffmpeg.org) (GPL static build) | GPL-2.0-or-later / GPL-3.0 | `yt-dlp/FFmpeg-Builds` GitHub releases |
| [Deno](https://deno.com) (JS runtime for YouTube extraction) | MIT | `denoland/deno` GitHub releases |

Because these are fetched from their publishers at the user's request, no FFmpeg/yt-dlp/Deno binaries
are included in this repository or in the release archives, so no source-offer or licence-text
obligations for them fall on this project. **If you ever bundle ffmpeg yourself**, you must ship the
GPL text, a notice, and an offer of the corresponding source for that exact build.
